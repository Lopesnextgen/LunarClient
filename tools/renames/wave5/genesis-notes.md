# Genesis module — findings and WIP (2026-09-16)

`com.moonsworth.lunar.genesis` (1,753 files) is the genesis module decompiled:
**a minified/relocated Guava 29.0-jre** (~1,600 classes) plus a few module
classes (bootstrap, mixins, Sentry glue). Two generations coexist: an earlier
rename wave named ~800 classes (`Preconditions`, `ImmutableList`, ...) and the
rescue sweep re-added the pre-rename copies (`MixinHelper*`, `Abstract*`).

## What was tried

`tools/make_genesis_repoint.py` builds a `genesis.X -> com.google.common.Y`
map (score-based matching + manual overrides), `tools/repoint_external.py`
deletes the copies and repoints every reference. Applying the **full** map
(1,191 rows) reached **4,391 -> 3,999 failing files (-392)** but introduced 135
NEW failures: Guava internals that are **package-private** (`AbstractMultiset`,
`MapMakerInternalMap`, `LocalCache`, anonymous `$1` classes) cannot be
referenced from `com.moonsworth.*`, and consumers that `extend` a copied class
stop satisfying the real class's abstract API.

The map generator now filters targets by access flags (`tools/pair_shaded.py` +
`make_genesis_repoint.py`), which leaves **390 public-target rows**. Even that
subset still breaks ~245 files: the *families* must be handled together (outer
+ nested + subclass consumers), not per class.

## Next step (family-aware pass)

1. Group genesis files into "families" = an outer class + its `Outer$Inner`
   flat files + the classes that extend/implement them.
2. For a family: map only if the whole family resolves to **public** Guava
   APIs; otherwise keep it and finish its names with the class-rename
   workstream (real Guava simple names, `genesis` package stays).
3. Delete family-wise, repoint consumers to the public API, then gate. Repeat.
4. The 390-row map and all findings are kept; the tools are re-runnable.

The map is generated by `python3 tools/make_genesis_repoint.py` (expects the
reference jars under `/tmp/opencode/reference/`).

## Outcome (2026-09-16, same session)

Executed as a **full removal** instead of a family repoint:

* `com/moonsworth/lunar/*.java` (963 shaded Jackson classes) deleted; 100
  consumers (98 in `client{,/cosmetics}/inactive`, `Fishing2`,
  `network/mixin/MixinHelper7`) moved to `tools/rescue-quarantine/root-jackson/`.
  The 13 files still needed by compiling code were restored; `IEntitySelectorImpl`
  (Lunar glue) moved to `client.util.PredicateEntitySelector`; `Annotation27`
  replaced by real `com.fasterxml.jackson.annotation.JsonProperty`
  (jackson-annotations 2.15.0 dependency added) in 33 files.
* `com/moonsworth/lunar/genesis` (1,753 files, embedded Guava 29) fully removed;
  1,363 files moved to `tools/rescue-quarantine/genesis-module/`. External
  consumers were repointed to real Guava (guava 29.0-jre) where the target is
  public. The remaining inactive-area files are part of the Jackson/Guava port
  workstream (they need member-level translation, not copies).
* `com/moonsworth/lunar/forge/lib` (1,102 shaded third-party files, excluded
  from the compile) deleted; all 11 consumers were already failing.

**Result:** failing files 4,391 -> 3,304 (-1,087 net; 1,116 fixed, 29 new —
all restored inactive-area files whose Jackson/Guava members still need the
port). No obfuscated library blobs remain under `src/main/java`.
